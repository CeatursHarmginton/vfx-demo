# Sakuga VFX Quest 🇻🇳 — Đại Vũ Trụ Hiệu Ứng Hoạt Hình 2D

Bộ sưu tập tương tác **Sakuga 2D Cel-Shaded UI Controls, Nhân Vật Chibi & Siêu Bom Toàn Màn Hình** xây dựng thuần Web Components + HTML5 Canvas (`Path2D`, vật lý lò xo `Spring`, âm thanh Web Audio tổng hợp trực tiếp, không dùng thư viện ngoài).

## Tính năng nổi bật
- **11 UI Controls chuẩn Sakuga VFX** (`button`, `slider`, `checkbox`, `progress`, `input`, `tabs`, `toast`, `rating`, `radio`, `tooltip`, và công tắc chất lỏng 43 frames `toggle`) Việt hóa 100% chữ truyện tranh (*BÙM!!, XOẸT!!, ẦM ẦM..., VÚT!!, BỤP!, TÁCH!*).
- **Hành trình 5 Bước liên hoàn**: Khởi nguồn mạch nước & mở Master Pokéball ➔ Tích điện Pikachu 100.000V & tứ tuyệt kỹ công kích Vua Slime Thủy Tinh (Sét Phân Nhánh, Tam Kiếm Khí, Sóng Thần Hokusai, Trụ Pha Lê 3D) ➔ Phù Thủy Sao Kirby hút & phun thần chú Tiếng Việt ➔ Tụ mây bão 100% ➔ **Kích nổ Rương Kho Báu Thần Thoại tràn 100% màn hình**.
- **Kho 4 Siêu Bom Tận Thế (`<sakuga-mega-bomb>`)**: *Bom Hố Đen Vũ Trụ*, *Bom Hạt Nhân Hỏa Ngục*, *Bom Bão Từ 1 Tỷ Volt*, và *Bom Hỗn Mang Neon*.

## Cách chạy & Đóng gói 1 File HTML
- **Mở nhanh không cần cài đặt**: Mở trực tiếp `sakuga-multiverse-single.html` hoặc `index.html` trên trình duyệt.
- **Chạy local server**:
  ```bash
  node serve.mjs
  ```
  Sau đó truy cập `http://localhost:8088/`.
- **Gộp toàn bộ mã nguồn thành 1 file HTML duy nhất (tự động xóa sạch 100% comment)**:
  ```bat
  runArchive.bat
  ```
